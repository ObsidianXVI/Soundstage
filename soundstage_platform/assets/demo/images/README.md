# Demo images

All four images are procedurally generated by `tool/gen_demo_images.dart`
(pure Dart, no third-party code or source imagery), so there are no licence
constraints. Regenerate them from `soundstage_platform/` with:

```
dart run tool/gen_demo_images.dart
```

| File | Size | Used by |
|---|---|---|
| `hero_dusk.png` | 1600×1000 | Hero scene background (focal point on the sun, 0.68/0.42) |
| `card_forest.png` | 800×500 | Card 1 |
| `card_sea.png` | 800×500 | Card 2 and the quote scene |
| `card_dunes.png` | 800×500 | Card 3 |
