# Editor design system

Tokens and components for the editor's own chrome. Story styling uses IR
tokens; the two never mix. Gallery: `/demo/design-system`.

## Tokens (`tokens/`)

- `SsColors` (dark, light): surfaces 0-3, borders (subtle, default, strong),
  text (primary, secondary, disabled, on-accent), accent (+ hover, pressed,
  text), selection, danger, warning, success, focus ring, hover/pressed
  layers, scrim. WCAG AA is asserted in `test/design_system/tokens_test.dart`.
- `SsTypeScale`: Inter at 11/16, 12/16, 13/20, 14/20, 16/24, 20/28 (+ tabular
  numerics, overline).
- `SsSpace` (4 px grid), `SsRadius`, `SsElevation` (e0-e3), `SsMotion`.
- `SsTheme` / `SsScope`: provide the theme, a transparent Material, the default
  text style and icon theme. `context.ss` reads it.

## Assets and licences

- UI font: **Inter** variable (opsz, wght), SIL OFL 1.1, from
  google/fonts (`ofl/inter`). `assets/fonts/inter/`, licence in `OFL.txt`.
  Bundled; nothing is fetched at runtime.
- Icons: **Lucide** (lucide-static 1.61.0), ISC licence (the Feather-derived
  icons are MIT); `assets/fonts/lucide/`, licence in `LICENSE.txt`. We bundle
  the font ourselves rather than depend on a pub package (the official
  `lucide_icons` is stale; the others are third-party forks). `SsIcons` is
  generated by `tool/gen_lucide_icons.dart` as const `IconData`, so release
  builds tree-shake the font (932 KB to ~27 KB).

## Components (`components/`)

Every component has hover, pressed, disabled and keyboard-focus states and a
semantics label. Keyboard focus rings show only after keyboard input
(`SsInputModality`).

Panel (collapsible), tabs, tree row (indent, disclosure, icon, inline rename,
visibility and lock toggles), number field (scrub, Shift x10 / Alt x0.1,
arrows, arithmetic, units, Mixed, clamp, Enter/blur/Esc), text field, colour
swatch, colour field, colour picker (HSV area, hue, alpha, hex/RGB/HSL,
eyedropper where the browser has the EyeDropper API), segmented control, toggle,
checkbox, dropdown, menu and context menu, tooltip, dialog, toast, alignment
matrix, constraints widget (inline segmented choices). Overlays (menu, dropdown, tooltip)
share `showSsPopover`.
